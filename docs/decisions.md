## 2026-09-30：採用靜態多頁教材索引

**背景**：網站需以 8 張首頁卡片分流至不同的 HTML 頁面，並在各頁依科目連結本機 PDF。

**決定**：使用 HTML5、CSS3 與原生 JavaScript（目前無需 JavaScript），首頁加上 8 個獨立教材分類頁，共用 `styles.css`。

**考慮過的替代方案**：
- 單頁篩選介面：不符合每張卡片要連至不同 HTML 的需求。
- 前端框架：目前教材數量少，會增加建置與維護負擔。

**影響**：新增教材時需確認分類後，手動在對應 HTML 頁新增連結；無須安裝套件或啟動伺服器。

**狀態**：已採用

## 2026-09-30：自然科依年級調整名稱

**背景**：國中教材的自然科在不同年級有不同常用名稱。

**決定**：7 年級網站顯示「生物」；8、9 年級網站顯示「理化」。

**影響**：後續新增教材或調整分類頁時，需依年級使用對應名稱。

**狀態**：已採用
