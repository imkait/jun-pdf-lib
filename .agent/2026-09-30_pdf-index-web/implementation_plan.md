# Implementation Plan：教材 PDF 索引網頁初版

## Scope

建立首頁與 8 個獨立學期／分類頁。各頁依國文、自然、地理、歷史、公民主題呈現教材，並在「8年級第1學期」頁連結現有 7 份 PDF。

## Approach

- 建立 `index.html` 作為 8 張入口卡片，另建立 8 個獨立 HTML 頁面。
- 使用共用 `styles.css`，避免重複樣式；不引入框架或建置工具。
- 以現有檔名作為「8年級第1學期」教材資料來源；其他學期顯示尚無教材。
- 採用校園圖書館索引卡視覺，同時維持手機與桌面可用性。
- 完成後更新交接狀態與變更紀錄。

## Files to modify

- `index.html`、8 個學期／分類 HTML 頁面與 `styles.css`（新增）：教材索引網站。
- `handoff.md`：記錄完成狀態與下一步。
- `CHANGELOG.md`：記錄本次網頁初版。
- `.agent/2026-09-30_pdf-index-web/walkthrough.md`（新增）：交付與驗證紀錄。

## Risks

- 未來新增不同學年度或科目的教材時，須先取得使用者確認後再增補連結。
- PDF 路徑包含中文；頁面使用相對路徑，應保留現有資料夾與檔名。
